# Experiment 5: ReactJS Practice & Todo Application

## 📌 Overview

This experiment focuses on learning the basics of ReactJS, including component creation, rendering, and event handling. It also includes implementation of a simple Todo Application using React.

---

## 🎯 Objectives

* Understand the concept of React components
* Learn how to render elements using ReactDOM
* Practice event handling in React
* Build a simple interactive Todo Application

---

## 🛠️ Technologies Used

* HTML
* JavaScript
* ReactJS

---

## 📂 Contents

This experiment includes:

1. **React Practice Programs**

   * Basic component creation
   * Rendering elements using `ReactDOM.render()`
   * Understanding JSX (if used)

2. **Todo Application**

   * Add tasks dynamically
   * Display list of tasks
   * Mark tasks as completed (strike-through)

---

## 🚀 How to Run

1. Open the project folder
2. Install dependencies (if using React setup):

   ```
   npm install
   ```
3. Start the application:

   ```
   npm start
   ```
4. Open browser and go to:

   ```
   http://localhost:3000
   ```

---

## 📸 Features of Todo App

* Add new tasks
* Display tasks instantly
* Click on a task to mark it as completed

---

## 🧠 Learning Outcomes

* Basics of ReactJS
* Difference between DOM and Virtual DOM
* Component-based architecture
* Handling user events in React

---

## 📌 Conclusion

This experiment helped in understanding the fundamentals of ReactJS and building a simple interactive application using components and state management.
