# Experiment 6: MERN Stack Application

## 📌 Overview

This experiment demonstrates the development of a full-stack web application using the MERN stack. The project is divided into frontend and backend components, enabling interaction between the user interface and database.

---

## 🎯 Objectives

* Understand full-stack development using MERN
* Learn integration between frontend and backend
* Implement CRUD operations using APIs
* Manage data using MongoDB

---

## 🛠️ Technologies Used

* MongoDB
* Express.js
* ReactJS
* Node.js

---

## 📂 Project Structure

```
mern-stack/
│
├── backend/      → Node.js + Express server
├── frontend/     → React application
```

---

## ⚙️ Backend Details

* Built using Node.js and Express
* Handles API requests
* Connects to MongoDB database
* Performs CRUD operations

---

## 💻 Frontend Details

* Built using ReactJS
* Provides user interface
* Sends requests to backend APIs
* Displays dynamic data

---

## 🚀 How to Run the Project

### 🔹 Step 1: Backend Setup

```
cd backend
npm install
npm start
```

---

### 🔹 Step 2: Frontend Setup

```
cd frontend
npm install
npm start
```

---

## 🌐 Application Flow

1. User interacts with frontend (React)
2. Frontend sends request to backend (Express)
3. Backend processes request and interacts with MongoDB
4. Response is sent back to frontend
5. Data is displayed to the user

---

## 📸 Features

* Add data
* View data
* Update data
* Delete data

---

## 🧠 Learning Outcomes

* Understanding of MERN architecture
* API handling using Express
* Component-based UI in React
* Database integration with MongoDB

---

## 📌 Conclusion

This experiment helped in understanding how a complete full-stack application is built using the MERN stack, integrating frontend, backend, and database efficiently.
